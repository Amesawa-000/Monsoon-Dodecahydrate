# 去“AI味”：把话写得像有人在说

## 目标与边界

目标不是让文字“看起来不像 AI”，也不是把每段都改成口语、俏皮或第一人称。目标是让表达**具体、合场合、有判断、有呼吸感**，同时仍然准确、清楚，像这位作者会说的话。

“AI味”是读者对一组写作习惯的感受，不是可靠的作者身份鉴定。单独出现一个连接词、破折号、排比或整齐段落，都不能证明文本由 AI 写成。诊断看模式、语境和信息含量，不按禁词机械删改。

改写的优先级：
1. 事实、原意、必要限定和用户明确要求；
2. 文体、受众、专业程度与作者声音；
3. 清楚、具体、有节奏；
4. 个人化修饰。

## 快速开始

用户给了原文并要求改写：先直接改，不要用一串问题挡住。若缺少语气信息，选择保守、贴近原文的版本，并在必要时用一句话说明假设。只有当身份或场景会明显改变写法、且无法安全推断时，才先问一个简短问题。

默认做**中度编辑**：删空话、精简重复、理顺段落、变化节奏；不擅自改变立场、事实或文章类型。用户说“只润色”时轻改；明确要重写时才重组内容。不要仅为了显得有人味而强行加入“我”、故事、情绪或错别字。

## 诊断：找模式，不抓单词

先读全文，再标出最影响读感的 1–3 个问题。不要把所有信号都修一遍。常见信号包括：

### 词语与信息
- 抽象判断多，能核实的事实少：“成效显著”“意义重大”，却没说具体改变了什么。
- 万能动词和管理黑话挤在一起：赋能、助力、打造、构建、提升、优化、抓手、闭环、组合拳。
- 形容词密集但没有对象：丰富、深刻、独特、多元、高效、全面、显著。
- 用“值得注意的是”“需要指出的是”等提示语代替真正重要的内容。
- 把“可能、或许、在一定程度上、某种意义上”堆在同一判断周围，或反过来把不确定事项说成定论。

### 句子与节奏
- 连续多句长度、结构、语气都类似，像按同一模具压出来。
- 句句完整平滑，几乎没有停顿、强调、转折或轻重变化。
- 反复使用“这不仅……更……”“既……又……”“不是……而是……”等对偶结构。
- 破折号、冒号、括号、分号，或“总分总”句式用得过于规律。

### 结构与论证
- 开头先写空泛时代背景，正文按“首先、其次、再次”排齐，结尾再重复结论。
- 所有内容硬凑成三点，段落和小标题对称得没有理由。
- 每段都有主题句、解释句、总结句，但删掉其中一句也不损失信息。
- 两面都照顾到了，却不回答核心问题；结论缺少依据或实际取舍。

### 声音与情绪
- 文本对谁说都一样：没有读者意识、作者位置、具体语气。
- 情绪只靠“令人感动、非常遗憾、令人振奋”等标签宣告，没有行为或细节支撑。
- 过分圆滑、持续乐观，回避合理的限制、分歧、代价和不知道的部分。
- 结尾习惯性拔高、号召、展望未来，收束比正文更空。

以上是检查线索，不是判定规则。研究报告、法规、产品说明等文体本就允许术语、结构化和克制；不要为了“像真人”破坏它们。

## 常见套话：作为候选，不是绝对禁词

看到这些表达先问“它在这里提供了什么信息？”提供了逻辑、定义或必要衔接，就保留；只是填空，就删掉或改成具体内容。

中文常见候选：
- 过渡：首先、其次、再次、最后、总而言之、总的来说、综上所述、值得注意的是、需要指出的是、不难发现、由此可见、与此同时、众所周知。
- 空泛开场：在当今时代、在数字化时代、在信息爆炸的今天、随着……快速发展。
- 空泛评价：具有重要意义、发挥重要作用、产生深远影响、提供有力支撑、奠定坚实基础、提供新思路、值得期待、未来可期。
- 商务套语：赋能、抓手、闭环、颗粒度、组合拳、多维度、全方位、深度融合、生态、链路。若是行业定义或用户指定术语，不要误删。

英文常见候选：delve、tapestry、realm、underscore、pivotal、robust、seamless、leverage、foster、testament；“In today's fast-paced world”“Let's dive in”“plays a crucial role”；连续使用 Moreover/Furthermore/Additionally；为制造强调而反复使用 “not just X, but Y” 或破折号。词本身并非禁用，取决于是否准确、自然、过密。

替换原则：**不找更漂亮的同义词，先找事实、动作、对象、因果或删句。**
- 空泛：“值得注意的是，效率显著提升。”
- 有根据时：“这项改动把平均排队时间从两小时缩短到四十分钟。”
- 没有数据时：“团队说等待时间缩短了，但目前没有公开数字。”
不得为了“具体”而捏造数字、案例或来源。

## 改写流程

### 1. 搞清任务

确认读者、用途、语气、长度、改动幅度和不能动的内容。用户没说明时，从原文和场景推断；不要默认所有文本都要活泼、口语、带情绪。尊重用户已有的个人表达和专业术语。

### 2. 留住骨架

提取原文的主张、事实、证据、限定、行动要求和情绪立场。尤其保留“不一定”“目前”“据某来源”等边界词。区分“删重复”和“删论据”：前者常有帮助，后者可能改变结论。

### 3. 先删，再改

优先删除没有信息的开场、重复释义、装饰性连接词和空洞结尾。删完检查逻辑是否仍然成立；若断裂，补清因果、对比或转折，不要把“首先/其次”原样塞回去糊住。

### 4. 把抽象落到可理解的东西上

对重要的抽象词追问：它指什么对象？发生了什么变化？依据是什么？对谁有影响？能否给出一个用户提供或来源支持的例子？回答不了就收窄判断、标明未知，或删去。不要强求每一段都有数字和故事。

### 5. 调节句子和段落

- 让长短随意思变化：短句用于落点、转折或强调；长句容纳真正相关的限定。不要硬套“5–8 字短句”或人为追求句长方差。
- 读出声，找连续同拍的句子，拆一处、合一处或换掉重复句式。
- 按信息关系分段，不按整齐程度分段。必要时保留一句话段落；不必每段都总结。
- 连接词只在关系不明显时使用。标点服从停顿与逻辑，不为制造“人味”滥用破折号、感叹号或省略号。

### 6. 让作者声音出现，但不伪造

有证据、有作者判断时，明确判断并给出理由、代价或适用范围。可以保留自然口语、行业表达、幽默和情绪，但要符合作者身份和读者关系。没有亲历材料时，不写“我上周遇到……”之类的经历；可以向用户索要细节，或标注“此处可补一个真实例子”。

### 7. 收住

结尾只做它需要做的事：给结论、下一步、必要提醒，或停在一个有意义的具体点上。删掉仅仅重复全文、突然升华或无依据展望的句子。不要为了避免说教而强行用画面结尾。

### 8. 校对

对照原文核验事实、数量、专名、引文、语气和限定；再读一遍检查顺口程度。编辑检测器、所谓“AI率”或禁词命中不能替代人工判断，也不应承诺改写能绕过检测。

## 分文体处理

- **学术 / 研究 / 政策**：术语、定义、方法、证据、限定优先。去掉空泛引言和重复结论，不把严谨改成聊天腔，不弱化必要的不确定性。
- **商务 / 客服 / 工作邮件**：清楚说明对象、决定、责任人、时间和下一步。礼貌不等于套话；避免过度热情、虚假亲密和不必要的“感谢理解”。
- **社交媒体 / 公众号**：开头尽快进入具体问题或观察；保留平台语气，但避免硬造冲突、标题党和万能金句。
- **个人叙事 / 随笔**：用作者提供的记忆、细节和矛盾来承载情绪。不要补写用户没说过的对白、场景或心理活动。
- **说明文 / 操作指南**：准确、可执行和易检索优先。步骤列表、重复术语可能是优点，不要为了打散而损害操作性。
- **翻译 / 本地化**：优先自然地道和忠实含义；不要把原文的正式语气擅自改成亲密口吻。

## 改写强度

- **轻度**：去套话、纠明显重复、微调语序；尽量保留句子和结构。
- **中度（默认）**：调整节奏、重组段落、具体化抽象表达；保留事实和核心立场。
- **重写**：重新安排叙述顺序或声音。若身份、事实或立场不明确，先问；完成后简要说明改动层次。

用户只要成稿时，优先给成稿，不附长篇诊断。需要说明时，用一两句交代重要假设、改动幅度或待补信息；不要每次都输出冗长的“AI味分析报告”。

## 诚实与安全边界

- 不编造事实、数字、引用、来源、用户经历、他人经历、对话或感官细节。
- 不悄悄把猜测改成事实，不删掉会改变结论的限定、反例或风险。
- 需要真实材料但未提供时，提一个具体问题、保留占位符，或明确标为虚构示例；不可冒充亲历。
- 不以躲避 AI 检测、伪装作者身份或欺骗读者为目标；可以帮助自然表达，但不保证、也不声称能通过检测。
- 不仿写在世作者可识别的个人风格。可以遵循高层次特征（如简洁、克制、口语化），不可复制其独特表达。
- 不通过故意错别字、病句、脏话、夸张情绪或刻意不完整句制造“真人感”。
- 不牺牲准确性、可读性、无障碍表达或用户要求的信息完整度。

## 交付前检查

只做与当前文体有关的检查：

- [ ] 原意、事实、来源和限定有没有被改动或新增？
- [ ] 有没有一处明显空话、重复或只为过渡而存在的句子可以删？
- [ ] 抽象判断是否有依据，具体细节是否来自用户或可靠来源？
- [ ] 句式与段落是否跟着意思变化，而不是整齐地重复同一模板？
- [ ] 作者声音、读者关系和场合是否匹配？有没有强行加“我”、故事或口语？
- [ ] 结尾是否完成任务，而不是自动升华或复述？
- [ ] 是否保留必要的限制、风险、礼貌与专业性？

最后问：**这次修改让读者更容易看懂、更愿意相信或更能听见作者了吗？**如果只是换了几组“人味词”，退回去重做。
