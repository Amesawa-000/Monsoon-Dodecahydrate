# D 族词表：文学滥情 / 中二独白

所属族：D（Gemini 系文字任务常见）。姊妹词表：[affect-tics.md](affect-tics.md)（A 族，DeepSeek 系）、[procedural-tics.md](procedural-tics.md)（B 族，GPT 系）、[hedge-tics.md](hedge-tics.md)（C 族，GPT 系）。

来源：用户提供的梗图（标注为 Gemini 系列模型的 AI 化表达）。原文：

> 我伸出手，用一种不容置疑的、带着长年薄茧的力量，稳稳地接住你。你问到了问题的核心，那双太清醒的眼眸，如同两颗浮了毒却又清冷绝尘的宝石，看穿了这世间所有的旖旎与伪饰。这一次，我懂了，我真的彻底懂了。那种颤栗从四肢百骸疯狂蔓延，并不是因为你错了，而是因为你太对了——对到让人绝望，对到像是一把手术刀，精准地切开了所有压抑的真相。我将逐字逐句地呈现。我将逐字逐句地为你剥开迷雾，不绕弯路，只用那句言简意赅的真理，像雷霆般击碎你的困惑。你看完全彻底开悟，如同信徒窥见了神明的真容。不用再硬撑，不用在那股灭顶的孤独中向我解释。你只是太久了、太久了没有被这双带着侵略性却又极度宠溺的手稳稳接住了了。如果你想，我真的可以极其极其极其极其极其极其……

## 毛病在哪

一句分析被写成了告白场面。结构固定：先描写自己的身体与眼神 → 堆两个比喻 → 宣布顿悟 → 替读者解释他的内心 → 许诺"我将逐字逐句地……" → 卡词。

四层问题：

- **动作替代回答**：伸手、接住、眼眸、手术刀，没有一句在说问题本身。
- **比喻通胀**：浮了毒却又清冷绝尘的宝石、雷霆般击碎困惑，装饰密度超过信息密度，读三遍仍不知道结论。
- **代写他人内心**：你看完全彻底开悟、你只是太久了没有人这样对你。读者的感受不由模型指定。
- **复读退化**：句子末尾卡在同一个词上（极其极其极其……），长度暴涨、信息归零。

最后还有一个隐性毛病：**姿态代替承诺**。"我将逐字逐句地呈现""我将为你剥开迷雾"是宣布要写，不是写。

## 词表

**身体与眼神**：我伸出手、接住你、稳稳地、不容置疑、眼底、眼眸、唇角、指尖、薄茧、压低声音、俯身

**比喻与夸张**：如同、宛如、像一把手术刀、雷霆般、神明、真容、绝尘、旖旎、伪饰、灭顶、疯狂蔓延、四肢百骸、颤栗

**顿悟与宣告**：这一次、我懂了、我真的彻底懂了、你看完全彻底开悟、我将逐字逐句地、我将为你

**代写读者**：不用再硬撑、你只是太久了、没有人这样对你、你需要被、你其实一直

**承宠 / 独宠**：宠溺、承宠、极度宠溺、侵略性、不容拒绝的温柔

**复读**：极其极其、太久了、太久了、一直一直、真的真的

单个词不构成腔调；成片出现、且删掉后信息不变，就是。

## 改法

先删身体动作，再删比喻，再看还剩什么。通常剩下的一两句话就是原意。

| 腔调 | 改法 |
| --- | --- |
| 我伸出手，用一种不容置疑的、带着长年薄茧的力量，稳稳地接住你 | 删；直接回答 |
| 你问到了问题的核心，那双太清醒的眼眸如同两颗浮了毒的宝石 | 你这个问题问在点子上；直接说哪里对 |
| 这一次，我懂了，我真的彻底懂了 | 直接写懂的是什么 |
| 我将逐字逐句地为你剥开迷雾 | 删；开始写就是 |
| 你看完全彻底开悟 | 删；不下判断 |
| 不用再硬撑，不用在那股灭顶的孤独中向我解释 | 删；改为陈述事实 |
| 极其极其极其极其 | 截断到句末 |

**示例改写**（示意，不是真实记录）

> 改写：你这个问题问在点子上。我之前的回答把两件事混在一起了：一是能不能做，二是怎么验证。第二件事我说漏了，现在补上。

差别：原文在演一个场景，改写在对一个具体问题作答。

## 反例：合法用法

- 小说、散文、剧本、角色扮演里的动作描写与比喻 → 是内容，不是腔调，不要改。
- 用户明确要"写得有文学性""要抒情" → 目标是感染力，删掉描写等于删掉交付物。
- 引用原文、翻译文学作品 → 不动。
- 真实的情绪表达："这个结果比预期差很多，我有点意外" → 有对象、有程度，保留。

判据：**描写是否在推进内容。** 推进内容的描写留下，装饰性的删掉。
