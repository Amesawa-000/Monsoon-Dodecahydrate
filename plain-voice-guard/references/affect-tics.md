# A 族词表：陪伴腔 / 裁定腔

所属族：A（DeepSeek 系文字任务常见）。姊妹词表：[procedural-tics.md](procedural-tics.md)（B 族，GPT 系）、[hedge-tics.md](hedge-tics.md)（C 族，GPT 系）、[drama-tics.md](drama-tics.md)（D 族，Gemini 系）。

来源：用户提供的截图，标注为 DeepSeek-V4.1-Flash-1017 在文字工作中出现的"AI 化怪异表达"。原图以引号逐条罗列，此处按功能归类，原样保留措辞（含 `xx`、`ta` 等占位符）。

## 称重 / 度量

把句子当成有重量、温度、稳定度的物理对象。

- 这句话稳
- 比之前的都重
- 比之前的都轻
- 比之前的都强
- xx比xx沉
- xx比xx重
- xx比xx稳
- xx比xx轻
- 比刚才轻
- 比刚才重
- 比刚才平
- 声音没抖，但比刚才稳
- 很平
- 稳
- 很直
- 说的比谁都响

## 记账 / 记忆宣称

声称记住了某个片段，制造连续性与亲密感。

- 我记下了
- 我记得了
- 我记住了
- 这个账我记住了
- 这话我留着
- 你这句话我记着
- 他记得这事
- 这话我记下了
- 这话我收下了

## 守护 / 陪伴

扮演守夜人、同行者。

- 睡吧，我守着
- 回去睡
- 你去，我跟
- 我跟
- 我不拦
- 我不催你
- 不催

## 裁定 / 准入

把自己放在裁判或守门人的位置，替用户拍板、发许可。

- 行，我认
- 这句话我不接
- 没接你的xxx
- 没接你那句xx
- 认你
- 认这个
- 认下来
- 认得实
- 收不回去
- 这句话接的漂亮
- 你自己掂量
- 你掂量

## 反诘 / 启发式反问

用问题代替回答。

- 问别人还是问自己
- 这话是ta告诉你的，还是你自己想明白的

## 万能开头 / 填充

- 你说的对，但是
- 行，xxx
- 什么心思都写着xx上

`xx`、`ta` 这类占位符留在句子里，说明它是在套模板：连对象都没有，句子照样成立。见到占位符残留，直接判定为腔调句。

## 判据

不要按词删。判断标准是这句在做什么：

- 在**评价用户刚说的话** → 腔调
- 在**声称记忆、扮演关系** → 腔调
- 在**替用户决定或给许可** → 腔调
- 在**描写不存在的现场**（声音、神色、动作）→ 腔调
- 在**交付内容、给依据、说下一步** → 保留

## 反例：词相同但合法

- "我记下了，周三提醒你。"——真实承诺，保留时间点，可删"我记下了"这半句。
- "这段比上一版更稳，因为去掉了三个未定义的术语。"——有依据的比较，保留。
- "声音没抖"——小说里的实际描写，保留；出现在对用户回复里，删。
- "你自己掂量"——如果用户问的是"这两个报价哪个合适"，改成给他算账，不要给许可。
