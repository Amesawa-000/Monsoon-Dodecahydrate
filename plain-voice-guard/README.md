# plain-voice-guard

交付前自检用的写作 skill：识别并剔除模型特有的"表演性腔调"，让回复落在内容上，而不是落在某个角色上。

## 它解决什么问题

模型在做文字工作时，常会漏出一种不属于写作的表达：

- **陪伴 / 裁定腔**：给句子称重、宣称记住、扮演守护者、替用户拍板
  —— "这句话稳""比之前的都重""我记下了""睡吧，我守着""这句话我不接""你掂量"
- **工程流程腔**：成串测试与运维术语，配上"我要开始……了"的宣言
  —— "核验、探针、审计、快照、哈希、夹具、门禁、回滚""先灰度，再放量""建立唯一基线"
- **谨慎不置可否腔**：同一条信息被否定五遍，绕完一圈没有结论
  —— "这不足以证明……不能断言……不能保证……我不是说不能做，而是……"
- **文学滥情腔**：把分析写成告白场面，动作、比喻、顿悟、替读者派心理
  —— "我伸出手……稳稳地接住你""这一次，我懂了，我真的彻底懂了""极其极其极其"

四类问题同源：**用姿态替代信息**。skill 给出的判据只有一条——这句话在交付内容，还是在展示"我是一个什么人/什么状态"。

## 特点

- **按模式判，不按模型判。** 内置的四族对应 DeepSeek / GPT / Gemini 的常见表现（其中 GPT 系占两族：术语洪水与否定堆叠），但族名只用来选择检查路径，不用于作者鉴定，也不据此对用户下判断。
- **先判族，再检查。** 命中某族 2 个以上信号才跑该族检查；都未命中就不改，避免过度清洗。
- **删句，不换同义词。** 腔调句整句删掉；删完确实缺信息，才补内容。
- **有边界。** 角色扮演、小说对白、剧本台词、引文译文、用户原句、代码与日志不动；真实的谨慎、未测项、风险提示必须保留。
- **静默执行。** 回复里不汇报"已自检""已去 AI 腔"。

## 使用方式

在 DSH 中作为 skill 自动加载，由 `description` / `whenToUse` 触发；也可以直接调用：

```
skill: plain-voice-guard
```

或在对话里说"用 plain-voice-guard 检查一下这条回复"。

判断依据、族识别表、四族检查清单（§A 五问 / §B 三问 / §C 三问 / §D 三问）、改写示例都在 `SKILL.md`；完整词表与反例在 `references/`：

| 文件 | 内容 |
| --- | --- |
| `SKILL.md` | 族识别、四族检查（§A 五问 / §B 三问 / §C 三问 / §D 三问）、快速扫描词块、边界、输出方式 |
| `references/affect-tics.md` | A 族词表（DeepSeek 系）：称重、记账、守护、裁定、反诘、万能开头 |
| `references/procedural-tics.md` | B 族词表（GPT 系）：测试、状态、工程对象、宣言句式 |
| `references/hedge-tics.md` | C 族词表（GPT 系）：否定判断、稀释词、元话语、抵消句式 |
| `references/drama-tics.md` | D 族词表（Gemini 系）：身体动作、比喻堆叠、顿悟宣布、代写读者、复读 |

## 安装

skill 是一个目录，入口文件为 `SKILL.md`（YAML frontmatter 需含 `name` 与 `description`，`name` 使用 kebab-case）。放进下列任一扫描根即可：

| 位置 | 说明 |
| --- | --- |
| `<DSH_HOME>/skills/` | 用户级（`DSH_HOME` 默认为当前用户主目录下的 `.dsh`） |
| `<项目>/.dsh/skills/` | 项目级，优先级更高 |
| `<项目>/.agents/skills/` | 项目级 |

DSH 的 skill 目录默认开启热加载，复制进去后无需重启。验证：在 skill 目录里能看到 `plain-voice-guard`，或用 `skill` 工具加载。

```
<DSH_HOME>/skills/plain-voice-guard\
├── SKILL.md
├── README.md
└── references\
    ├── affect-tics.md
    ├── procedural-tics.md
    ├── hedge-tics.md
    └── drama-tics.md
```
