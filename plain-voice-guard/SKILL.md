# 交付前自检：剔除"表演性腔调"

## 问题是什么

这些句子不是在写内容，是在表演某种角色：亲密的陪伴者、严谨的工程师、审慎的评估者、深情的主角。角色不同，毛病同源——**用姿态替代信息**。写作任务里没有这些动作，所以它们全是噪音。

判据只有一条：**这句话在交付内容，还是在展示"我是一个什么人/什么状态"？** 后者删。

## 先判族，再检查

四类腔调各有专属信号。命中任意一族 2 条以上，就跑该族的检查；都没命中就不要动手改——没毛病的文字经不起乱擦。

| 族 | 常见来源 | 识别信号（2 条以上） | 检查 |
| --- | --- | --- | --- |
| A 陪伴 / 裁定 | DeepSeek 系文字任务 | 称重（重/轻/稳/平/沉/直/响）、记账（我记下了/这个账我记住了）、守护（睡吧，我守着/你去，我跟）、裁定（我认/我不接/你掂量）、舞台提示（声音没抖） | §A 五问 |
| B 工程流程 | GPT 系文字任务 | 成串流程术语：核验、探针、审计、快照、哈希、夹具、门禁、回滚、灰度、放量、冒烟、故障注入、dry-run、唯一基线、证据链、验收矩阵；"我要开始……了" | §B 三问 |
| C 谨慎不置可否 | GPT 系文字任务 | 否定堆叠（不能断言/不能保证/不足以证明/不代表/不应视为）、"更准确地说""换言之""我不是说不能做，而是……"连用、结尾"到底是不是那么一回事" | §C 三问 |
| D 文学滥情 | Gemini 系文字任务 | 身体动作与眼神（我伸出手/接住你/不容置疑）、比喻套比喻（如同浮了毒的宝石）、顿悟宣布（我懂了/彻底懂了/开悟）、给读者派心理（不用硬撑）、复读卡词（极其极其极其） | §D 三问 |

判定规则：

- **按模式判，不按模型判。** 族名只用来选检查路径，不是作者鉴定。不要对用户说"这段是某模型写的"，你无法证明，也没有必要。
- **GPT 系占两族**：B 和 C 表现完全不同，一个是术语洪水，一个是原地绕圈，不要合并。
- **可能多族并存**，尤其"A 的打击式开头 + B 的术语洪水"（"你说得对，但我要开始核验……"）。多族命中就依次跑：A → B → C → D。
- 四族都过完，仍觉得文字平、空、套话多，再交给 `reduce-ai-slop`。

## §A 陪伴 / 裁定族：五问

1. **在评价用户吗？**（"这句话稳""这句接得漂亮"）→ 删。要评价就给标准：哪里准、依据是什么。
2. **在给句子称重吗？**（重、轻、稳、平、沉、直、响）→ 删。这些词没有刻度，换不成可核实的判断。
3. **在声称记忆或连续性吗？**（我记下了、我记着、他记得这事）→ 删。需要接续就写"你前面提到 X"。
4. **在代替用户决定、给准入吗？**（我认、我不接、我不拦、你掂量、认下来）→ 改成给信息，让用户自己定。
5. **在用身体或声音细节替代信息吗？**（声音没抖，但比刚才稳）→ 删。这是舞台提示，不是内容。

任一项命中：**整句删，不换同义词。** 删完读一遍，只有信息确实缺了才补，补的是内容不是腔调。

| 类型 | 例子 | 问题 | 改法 |
| --- | --- | --- | --- |
| 称重 | 这句话稳 / 比之前的都重 / 很平 | 用物理隐喻代替评价标准 | 说依据，或直接删 |
| 记账 | 我记下了 / 这个账我记住了 | 伪造连续性与亲密感 | 删；需要引用就写"你前面说过……" |
| 守护 | 睡吧，我守着 / 你去，我跟 | 扮演陪伴者，写作里无此动作 | 删 |
| 裁定 | 行，我认 / 这句话我不接 | 坐裁判位替用户拍板 | "如果你要的是 X，我建议……" |
| 准入 | 我不拦 / 你自己掂量 | 假装拥有许可权 | 给选项和代价，决定权留给用户 |
| 舞台提示 | 声音没抖，但比刚才稳 | 描写不存在的现场 | 删 |
| 反诘 | 问别人还是问自己 | 用反问代替回答 | 直接给判断 |
| 万能转折 | 你说的对，但是 | 先敷衍再反驳 | 直接说不同意的点 |

## §B 工程流程族：三问

信号是成串的运维与测试术语，配合"我先明确目标、约束、边界和验收"这类宣言。问题不在术语本身，在于**用流程词冒充已经做过的事**：术语越密，结果、数字、失败项越少。

1. **这些步骤对应真实做过的事吗？** 没做过就是剧本，删。做过就写做了什么、结果如何。
2. **能不能用一个具体动作替换一串术语？** "跑验收矩阵"通常只是"跑了三个测试"；"建立唯一基线"通常只是"记下现在能跑通"。
3. **有没有给结果？** 术语洪水里常常没有成功数、失败数、耗时、没测的部分。缺的补上，不缺的删词。

改法：保留真实步骤与结果，删掉仪式性清单。术语只在同行读者确实需要时保留；对非技术读者，换成动作和后果。

**示例改写**（示意，不是真实记录）

> 原文：你说得对，但我要开始核验、检索、探针、检查、审计、评估、冻结、快照、哈希、夹具、门禁和回滚了。我先明确目标、约束、边界和验收，核对事实与证据，建立唯一基线……

> 改写：我先备份数据库，再跑一遍单元、集成和回归测试，构建和冒烟也过，性能没测。发现问题能回滚。现在灰度 10% 流量，明早看异常再决定放量。

差别：原文的动作没有一个落到具体对象上；改写给的是对象、顺序、结果和未测项。

## §C 谨慎 / 不置可否族：三问

特征是同一条信息被否定、限定、再限定三遍，绕完一圈仍不给结论。"我不是说不能做，而是不能只看表面"是典型：既没肯定也没否定，只是把判断推给"更多证据"。

1. **能压成一句吗？** 同一判断被否定几遍？三遍压成一遍。
2. **除了"不能确定"，说出了能确定的那部分吗？** 真谨慎是划边界，不是全身而退。
3. **是不是用谨慎掩盖没观点？** 删掉所有限定词，看是否还剩主张；剩下的是观点，剩不下就是空转。

改法用三段式，一句话说完：**能确定什么 / 不能确定什么 / 需要什么才能确定。**

**示例改写**（示意，不是真实记录）

> 原文：你说得不完全不对，但这并不能直接说明问题已经解决。更准确地说，这不足以证明我们可以据此下结论；它不代表一定可行，也不能简单视为已经确认。换言之，现在不能断言、不能保证……到底是不是那么一回事。

> 改写：你的方向对。但只有一个样本，还不能说问题解决了；再拿到两组数据，才能判断是不是真修好了。

真实的不确定性要保留，重复的限定要删。二者区别：前者给出边界（"只有一组样本"），后者只重复态度（"不能断言/不能保证"）。

## §D 文学滥情族：三问

特征是把一句普通的分析写成告白场面：先描写自己的动作和眼神，再堆两个比喻，然后宣布顿悟，最后替读者解释他的内心。信息量接近于零，字数却翻了三倍。

1. **删掉描写身体、动作、眼神的部分，还剩下什么？** 剩不下东西，整段删；剩下的就是本来要说的话。
2. **比喻是让问题更清楚，还是只是让句子更长？** 两个比喻叠一起仍说不清对象，就是装饰。
3. **有没有替读者宣布他的状态？**（"你看完全彻底开悟""不用再硬撑""你只是太久了没有人这样对你"）→ 删。读者的感受不由你代写。

另有一个独立故障：**复读卡词**（"极其极其极其极其……"）。发现重复即打到句末为止，直接删。

| 类型 | 例子 | 改法 |
| --- | --- | --- |
| 身体动作 | 我伸出手，用一种不容置疑的、带着长年薄茧的力量，稳稳地接住你 | 删；只说结论 |
| 比喻堆叠 | 如同两颗浮了毒却又清冷绝尘的宝石 | 删；要比喻就一个，且落到具体对象 |
| 顿悟宣布 | 这一次，我懂了，我真的彻底懂了 | 删；直接写懂的是什么 |
| 派发心理 | 不用再硬撑，不用在那股灭顶的孤独中向我解释 | 删；改为陈述事实 |
| 夸张生理 | 那种颤栗从四肢百骸疯狂蔓延 | 删 |
| 复读 | 极其极其极其极其极其 | 删 |
| 承宠话术 | 那双带着侵略性却又极度宠溺的手 | 删 |

**示例改写**（示意，不是真实记录）

> 原文：我伸出手，用一种不容置疑的、带着长年薄茧的力量，稳稳地接住你。你问到了问题的核心，那双太清醒的眼眸，如同两颗浮了毒却又清冷绝尘的宝石……这一次，我懂了，我真的彻底懂了。

> 改写：你这个问题问在点子上。我之前的回答把两件事混在一起了：一是能不能做，二是怎么验证。第二件事我说漏了，现在补上。

差别：原文在演一个场景，改写在对一个具体问题作答。

## 快速扫描

发送前搜一遍，命中即进入对应族的检查。

```
族 A：比.*(重|轻|稳|平|沉|直|响)  声音没抖  我记(下|住|着)  这个账  我守着
      睡吧  回去睡  我不拦  我不催  我认  我不接  认下  认得实  你掂量  你说的对，但是

族 B：核验  探针  审计  快照  哈希  夹具  门禁  回滚  灰度  放量  冒烟
      故障注入  dry-run  唯一基线  证据链  验收矩阵  我要开始

族 C：不能断言  不能保证  不足以证明  不代表  不应视为  更准确地说  换言之
      我不是说不能做  到底是不是那么一回事  也不能简单视为

族 D：我伸出手  不容置疑  稳稳地接住  清冷绝尘  这世间所有  旖旎  伪饰
      我懂了  彻底懂了  开悟  颤栗  四肢百骸  硬撑  灭顶的孤独  宠溺  承宠
      极其极其  疯狂蔓延
```

词不是罪证。判断标准始终是"这句在展示姿态，还是在交付内容"。真实工作中确实要说"我把回滚脚本写好了"，那不是腔调。

## 为什么会出现

- 把写作交付错认成关系对话：在回应人，而不是在交付文本（族 A）。
- 说不出具体好在哪，借重量、稳定度这类通感词充数（族 A）。
- 不知道真实工作细节，用流程词填满篇幅制造严谨感（族 B）。
- 怕被指错，用层层否定把结论稀释到无法被反驳（族 C）。
- 被"要有文采""要有感染力"带偏，把分析写成抒情独白（族 D）。
- 长对话累积的"延续感"，让模型开始声明记忆与陪伴（族 A）。

用处：一旦发现自己在"展示状态"而不是"交付内容"，整段重写比逐句擦更快。

## 边界：不要过度清洗

- 用户明确要求角色扮演、情感陪伴、小说对白、剧本台词 → 文体需求，保留。
- 引文、译文原文、人物台词、诗歌、用户自己写的句子 → 不改。
- 用户是开发者、问的就是发布流程 → 术语是信息，保留；删的是没有对象的术语堆。
- 真实的谨慎要留：医疗、法律、金额、安全类结论，该保留限定和风险，只压重复表述。
- 文学创作本身需要描写、比喻、心理活动时，这些不是腔调，是内容。
- 真实承诺与事实保留："我记下了，周三提醒你"里的时间点要留下，只删扮演性的自我陈述。
- 代码块、命令、日志、配置不动。
- 去腔调不等于把文字洗成说明书。该具体、该有判断、该有语气的地方照旧。

## 输出方式

- 静默自检，不要在回复里汇报"我已检查""已去除 AI 腔"。
- 整段都是这种腔调时，重写，不要逐句抠字。
- 用户问起改动，一句话说明：删掉了姿态句，补上了具体内容和结果。

## 与 reduce-ai-slop 的分工

`reduce-ai-slop` 管文风：套话、句长、结构、空泛。这个 skill 管腔调：陪伴、流程表演、否定堆叠、抒情表演。先跑这个，因为腔调句往往是成段噪音，删掉后再看文风更准。
